# BridgeLabz SIPP Training 2026

A comprehensive Java repository containing **Core Java**, **Object-Oriented Programming (OOP)**, and **Data Structures & Algorithms (DSA)** practice completed during the **BridgeLabz SIPP Training 2026**.

This repository is designed as a structured learning journey to strengthen Java programming fundamentals and build problem-solving skills for **placement preparation**. It includes classroom exercises, scenario-based problems, coding assignments, and hands-on implementations of important DSA concepts.

# Running the Programs

Clone the repository:

```bash
git clone https://github.com/TGCO10/BridgeLabz-SIPP-Training-2026.git
```

Open the project in **IntelliJ IDEA**, select any Java file containing a `main()` method, and run it.

Or compile and run from the terminal:

```bash
javac FileName.java
java FileName
```
